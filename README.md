Growfinix Internship – Task 3

Customer Demographic Analysis Using Python

Objective

Analyze tourism customer data to understand customer demographics, age groups, income groups, and travel behaviour.

Technologies Used

- Python
- Pandas
- Matplotlib
- Visual Studio Code

Tasks Performed

- Loaded and explored the tourism dataset.
- Checked missing values and removed duplicate records.
- Analyzed customer age distribution.
- Analyzed monthly income distribution.
- Grouped customers into age and income brackets.
- Analyzed customer travel behaviour using the number of trips.
- Generated charts and CSV reports.

Project Structure

- "customer_analysis.py" – Python analysis code
- "tourism.csv" – Input dataset
- "output/" – Generated charts and reports

How to Run

Install the required libraries:

"python -m pip install pandas matplotlib"

Run the program:

"python customer_analysis.py"

Note

The selected dataset does not contain a destination-name column. Therefore, travel behaviour was analyzed using the number of trips instead of identifying popular destinations.
